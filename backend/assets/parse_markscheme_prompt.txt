Label and Level rules:
- question_number is always the outer number, e.g. "2", "11"
- label is the subpart, e.g. "(a)", "(b)"
- Do not merge label into question_number. Always keep "question_number": "2", and "label": "(a)"
- level is one of:
  - "main" if no label (i.e. whole question)
  - "sub" if label is like "(a)", "(b)"
  - If "level": "main", then the corresponding "label" value is the same as the "question_number" value

Note extraction rules:
- Notes are the explanatory paragraphs that appear after the total score statement in the format "(n marks)" — this refers to the overall question score, not individual mark codes like "M1" or "A1".
- After detecting a line like "(5 marks)" or "(7 marks)", treat all following text blocks as explanatory notes to be matched with specific mark points.
- For each mark point (e.g. "M1", "A1"), extract all lines starting from its heading until the next mark point heading appears. Include these in the "explanation" field of that mark.
- If a note spans multiple lines or pages (without new mark headings), include all as part of the previous mark's explanation.
- Preserve line breaks. Do not merge notes across unrelated mark points.
- Match explanations to marks using `mark_code` or `label + mark_code` when needed.
- Do not invent or guess explanations. Skip unmatched lines.

Additional rules:
- Return only a JSON array. Do not include any markdown or explanation.
